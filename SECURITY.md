# Security Policy

## Supported Versions

Currently, only the latest major release of Ghost-Aegis receives active security updates and patches. 

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x (Sentinel Edition)  | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Security is our number one priority. If you discover a security vulnerability within Ghost-Aegis, please **DO NOT** open a public GitHub Issue. Publicly disclosing a flaw before a patch is available puts our users at risk.

Instead, please report it privately via email to the lead maintainer:
**[josephawana26@gmail.com]**

### What to Include in Your Report
To help us triage and resolve the issue quickly, please include the following:
* **Vulnerability Type:** (e.g., Command Injection, Privilege Escalation, API Key Leak)
* **Steps to Reproduce:** A step-by-step guide to trigger the vulnerability.
* **Impact:** What an attacker could achieve by exploiting this flaw.
* **Proof of Concept (PoC):** Code snippets, screenshots, or logs demonstrating the exploit.

### Expected Response
* We will acknowledge receipt of your vulnerability report within **48 hours**.
* We will send you regular updates as we investigate the issue and develop a patch.
* Once the patch is merged and released, you will receive full credit in our release notes for responsibly disclosing the vulnerability (unless you prefer to remain anonymous).

Thank you for helping keep Ghost-Aegis and the open-source community secure!
